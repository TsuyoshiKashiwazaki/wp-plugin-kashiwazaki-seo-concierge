== Description ==

Kashiwazaki SEO Concierge は、サイトの sitemap.xml と（存在すれば）llms.txt を解析してページを把握し、訪問者の自然言語の質問に対して、最も適切なサイト内コンテンツを AI が案内するフローティング型チャットボットです。

「関連ページを探す検索AI」と「回答文を作る回答AI」は別々に設定でき、OpenAI / GLM (Z.AI) / Ollama Cloud / OpenAI 互換の独自エンドポイントから選べます。

主な機能:

* sitemap.xml / llms.txt の解析とメタ情報のキャッシュ（カスタムテーブル + WP-Cron 差分更新）
* 埋め込み検索（コサイン類似度・正規化済みベクトルをパック保存）
* 回答と候補ページの提示（構造化出力に対応しないサービスでも動作）
* 検索AI・回答AIごとのサービス／モデル指定と、サービスごとのAPIキー保存
* 回答の根拠（一致理由・関連度スコア・最終更新日）の表示
* ゼロ回答時のフォールバック導線、回答キャッシュ、コスト上限サーキットブレーカー
* プロンプトインジェクション/乱用ガード、レート制限、ブロックリスト、PII マスク
* WordPress プライバシー API 連携、ログ保持期間の自動削除
* 会話ログ・クエリ分析（コンテンツギャップ可視化・CSV エクスポート）、GA4/dataLayer 連携
* アクセシブルな（WCAG 配慮）軽量フロント UI（jQuery 非依存）
* 拡張フックと REST API、品質テスト用サンドボックス

== Installation ==

1. プラグインを `/wp-content/plugins/wp-plugin-kashiwazaki-seo-concierge` にアップロードします。
2. 管理画面の「プラグイン」メニューから有効化します。
3. 管理メニュー「Kashiwazaki SEO Concierge」から、使う AI サービスの API キーと sitemap.xml / llms.txt の URL を設定します。
4. 「インデックス」タブで「今すぐ再構築」を実行してインデックスを作成します。

API キーは wp-config.php に定数で注入することもできます（データベースに保存せずに済みます）。検索AI用は `KS_CONCIERGE_EMBED_API_KEY`、回答AI用は `KS_CONCIERGE_CHAT_API_KEY` を定義してください。

== Frequently Asked Questions ==

= 質問はどこへ送信されますか？ =

質問は回答生成のため、管理画面で設定した AI サービスに送信されます。送信先のサービス名は、訪問者に表示する同意文とプライバシーポリシー推奨文にも自動で反映されます。PII（メール・電話番号・郵便番号など）は送信前に best-effort でマスクされます。

* 変更: 回答AIに渡す候補に最終更新日を添えるように。回答文で日付を示せるようになりました。
* 追加: 「分析」タブの履歴を1件ずつ／絞り込み単位でまとめて削除できるようになりました。
* 追加: AI呼び出しの失敗理由（サービス・モデル・時刻・内容）を管理画面に表示。成功すると自動で消えます。
* 追加: チャットの「考えています…」に回転インジケーターを表示。
* 変更: APIキーを使うサービスごとに保存。サービスを切り替えても前のキーが送られて認証エラーになることがなくなりました（既存のキーは自動移行）。
* 変更: サービス・接続先・モデル名を1組として保存。モデル名が空欄なら3項目とキーを変更前のまま維持します。
* 変更: 同意文とプライバシーポリシー推奨文に、実際の送信先サービス名を表示。
* 変更: 月額定額のサービスを従量課金として金額計算しないように（架空の金額で上限に達して停止する問題を防止）。
* 変更: 「優先して表示するURL」が検索結果の並び順（同点時）に反映されるように。保存で既存ページにも即反映。
* 変更: 回答キャッシュが、回答に影響する設定を含めて管理されるように（設定変更が即座に反映）。
* 変更: 連投制限をデータベース上の不可分な処理に変更。同時アクセスでの取りこぼしを解消。
* 変更: 課金上限の警告条件と回数上限の説明を実装に合わせて修正。接続先URLの既定値はプレースホルダー表示に。
* 変更: 管理画面のテストが公開用キャッシュを読み書きしないように。混雑時の再試行が待機指示を尊重するように。
* 修正: 挨拶や雑談への返答が定型文になる問題。
* 修正: 検索AIの設定変更後にインデックス再構築が予約されない問題。
* 修正: 暗号化に失敗する環境で保存済みAPIキーまで消える問題。
* 修正: マルチバイト拡張がない環境で分析タブが致命的エラーになる問題。
* 修正: 削除の確認ダイアログがセキュリティポリシー設定下で出ない問題。
* 修正: URL内の2文字を言語コードと誤認し、該当ページが検索から外れる問題。
* 修正: 大規模サイトでベクトルの一時保存が無言で失敗する問題。
* 修正: アンインストール時の削除漏れ（マルチサイト対応）。停止時にリンクチェックの予約が残る問題。
* セキュリティ: llms.txt 由来のURLで内部ネットワークを探索できる問題を修正。クリック記録を索引済みURLのみに限定。
